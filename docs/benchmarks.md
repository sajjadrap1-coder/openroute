# Honest performance methodology

- Always measure direct connection and candidate routes from the **same** machine, game/service, ISP and time window.
- Report both median and p95 end-to-end application RTT, jitter, UDP packet loss, connection success, bandwidth and unexpected disconnections.
- Prefer real game UDP RTT and packet-level measurements; TCP connect time alone is NOT a game ping estimate.
- Publish test count, destination/region (not identifying IP), measurement time and confidence intervals when possible.
- Include cold-start, path changes, congested connections and ISP-level blocking failure cases.
- No guarantee of unchanged ping, zero packet loss, universal availability, anonymity or sanction/account-policy bypass.
- Ensure consent and lawful access for all target endpoints and relay devices.
