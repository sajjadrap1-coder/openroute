# OpenRoute — اوپن‌روت

**پروژه متن‌باز شبکه غیرمتمرکز برای ویندوز و اندروید**

**وضعیت: نسخه ۰.۱ آزمایشی فقط ابزار بررسی شبکه و سیاست مسیر است؛ هنوز VPN یا نرم‌افزار عملی عبور از محدودیت‌ها نیست.**

سه حالت برنامه در نقشه راه:

- **Gaming:** اولویت با پینگ، جیتر، Packet Loss و مسیر UDP پایدار. هیچ مسیر جایگزینی نمی‌تواند کاهش یا ثابت‌ماندن پینگ را تضمین کند.
- **Smart Access:** انتخاب مسیر فقط برای دامنه‌ها و برنامه‌های مشخص، بدون عبور دادن تمام اینترنت از یک تونل.
- **AI & Developer:** دسترسی شبکه به ابزارهای هوش مصنوعی و توسعه‌دهندگان در چهارچوب قوانین و شرایط ارائه‌دهندگان؛ محدودیت حساب، هویت یا پرداخت با تغییر IP حل نمی‌شود.

طرح اصلی به **سرور مرکزی اجاره‌ای** وابسته نیست، اما برای اتصال به سایت‌ها به گره‌های خروجی داوطلب نیاز دارد. بلاکچین برای ترافیک کاربردی نیست و فعلاً اضافه نمی‌شود.

## اجرای نمونه اولیه

ابتدا Go نسخه ۱.۲۳ یا جدیدتر نصب باشد و در پوشه پروژه دستورهای زیر اجرا شوند:

```bash
go test ./...
go run ./cmd/openroute version
go run ./cmd/openroute probe --host example.org --port 443 --count 5
go run ./cmd/openroute route --mode gaming --host steamcommunity.com
go run ./cmd/openroute rank --mode gaming
```

- `probe` فقط زمان برقراری اتصال TCP را اندازه می‌گیرد؛ **پینگ واقعی بازی نیست**.
- `route` فقط تصمیم مسیر را نمایش می‌دهد و ترافیک واقعی را هدایت نمی‌کند.
- `rank` گره‌های فرضی را بر اساس شاخص‌های ورودی مرتب می‌کند.

برای وظایف توسعه به [`ROADMAP.md`](ROADMAP.md)، برای جزئیات معماری به [`docs/architecture.md`](docs/architecture.md) و برای مشارکت به [`CONTRIBUTING.md`](CONTRIBUTING.md) مراجعه کنید.

**مشارکت:** توسعه‌دهندگان Go، Kotlin، Windows، شبکه و امنیت می‌توانند از طریق Issue و Pull Request کمک کنند.

**مجوز:** MIT. استفاده از این نسخه به‌عنوان VPN ایمن یا محصول تجاری توصیه نمی‌شود.

## نسخه ۰.۲ آزمایشی: تونل واقعی TCP

اکنون ابزار جداگانه `openroute-tunnel` برای ساخت گواهی‌های TLS 1.3، اجرای گره خروجی داوطلب و پراکسی محلی HTTP CONNECT وجود دارد. این مرحله **انتقال واقعی TCP** را ممکن می‌کند، اما هنوز از UDP بازی، VPN کامل، اندروید یا کشف گره‌های P2P پشتیبانی نمی‌کند. نصب، محدودیت‌ها و هشدارهای امنیتی در [راهنمای راه‌اندازی فارسی](docs/tunnel-quickstart.fa.md) آمده است.
