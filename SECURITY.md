# Security policy

**Unreleased research prototype, not security audited.** The current CLI does not provide a VPN or network protection. Do not rely on it for confidential or adversarial network use.

If you identify a vulnerability, **do not** put exploits, credentials, private user data or exploit details in a public issue. Contact the repository owner privately through GitHub's private vulnerability reporting (if enabled) or another secure private channel listed by maintainers once the project is published.

No exit node shall be publicly enabled by default. Any future public relay requires prior review of authentication, consent, SSRF/private-network controls, abuse handling, update signing and privacy implications.
